# Probability Distributions Cheat Sheet

| Distribution       | Mean (μ)                          | Median                                      | Mode                                              | Variance (σ²)                  | Standard Deviation (σ)             |
|--------------------|-----------------------------------|---------------------------------------------|---------------------------------------------------|--------------------------------|------------------------------------|
| **Bernoulli(p)**   | p                                 | 0 if p<0.5, 1 if p>0.5, both if p=0.5     | 0 if p<0.5, 1 if p>0.5, both if p=0.5           | p(1-p)                         | √[p(1-p)]                          |
| **Binomial(n, p)** | np                                | Approximately np                            | ⌊(n+1)p⌋ (if (n+1)p is not integer)             | np(1-p)                        | √[np(1-p)]                         |
| **Poisson(λ)**     | λ                                 | Approximately (λ + 1/3 - 0.02/λ)           | ⌊λ⌋. If λ is integer, both λ-1 and λ are modes | λ                              | √λ                                 |
| **Uniform(a, b)**  | (a + b)/2                         | (a + b)/2                                   | No unique mode (all values equally likely)       | (b - a)² / 12                  | (b - a) / √12                      |
| **Normal(μ, σ²)**  | μ                                 | μ                                           | μ                                                 | σ²                             | σ                                  |

---

## Universal Statistics Formulas

### Arithmetic Mean
**x̄ = Σxᵢ / n**

### Population Variance
**σ² = Σ(xᵢ - μ)² / N**

### Sample Variance
**s² = Σ(xᵢ - x̄)² / (n - 1)**

### Population Standard Deviation
**σ = √σ²**

### Sample Standard Deviation
**s = √s²**

### Standard Error
**SE = σ / √n**

### Z-Score
**Z = (X - μ) / σ**

### Confidence Interval (95%)
**x̄ ± 1.96 × (σ / √n)**

---

## Quick Memory Tricks

### Bernoulli
- **Mean = p**
- **Variance = p(1 - p)**

### Binomial
- **Mean = np**
- **Variance = np(1 - p)**

### Poisson
- **Mean = Variance = λ**
- **SD = √λ**

### Uniform
- **Mean = Midpoint of interval**
- **Variance = (b - a)² / 12**
- **No unique mode**

### Normal
- **Mean = Median = Mode**
- **Variance = σ²**
- **SD = σ**
