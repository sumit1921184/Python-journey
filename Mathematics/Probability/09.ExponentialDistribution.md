# Exponential Distribution - Complete Detailed Notes

The **Exponential Distribution** is one of the most important distributions in statistics, especially in reliability engineering, queuing theory, and survival analysis. It models the **time between events** in a Poisson process.

---
## What is Exponential Distribution?

- Also known as the **Negative Exponential Distribution**.
- It is the **continuous counterpart** of the Geometric distribution.
- Used to model **waiting times** or **time until the next event** occurs.
- Key property: **Memoryless** (the only continuous distribution with this property).

### Types:
- Only **Continuous** version is commonly used (Discrete version is Geometric).

---

## Key Properties Table

| Property              | Formula                          | Description                                      |
|-----------------------|----------------------------------|--------------------------------------------------|
| **Mean (μ)**          | 1 / λ                            | Average waiting time                             |
| **Median**            | (ln 2) / λ ≈ 0.693 / λ           | Roughly 69.3% of mean                            |
| **Mode**              | 0                                | Highest density at the start                     |
| **Variance (σ²)**     | 1 / λ²                           | Same as (Mean)²                                  |
| **Standard Deviation (σ)** | 1 / λ                        | Equal to the mean                                |
| **Rate Parameter**    | λ (lambda)                       | Average number of events per unit time           |

---

## Formulas (Exponential Distribution)

### 1. Probability Density Function (PDF)

For **X ~ Exp(λ)**:

$$
f(x) = 
\begin{cases} 
\lambda e^{-\lambda x} & \text{if } x \geq 0 \\
0 & \text{if } x < 0
\end{cases}
$$

### 2. Cumulative Distribution Function (CDF)

$$
F(x) = P(X \leq x) = 
\begin{cases} 
1 - e^{-\lambda x} & \text{if } x \geq 0 \\
0 & \text{if } x < 0
\end{cases}
$$

### 3. Probability Between Two Values

$$
P(a < X < b) = e^{-\lambda a} - e^{-\lambda b}
$$

### 4. Survival Function (Important)

$$
P(X > x) = e^{-\lambda x}
$$

---



**Important Parameter Mapping:**

- `scale = 1/λ` (this is the **mean**)
- `loc = 0` (usually left as default)

**Note**: SciPy uses `scale` as the mean, not the rate.

---

### Code Examples

**1. Generate Random Numbers**
```python
# Exp with mean = 5 (λ = 0.2)
data = expon.rvs(scale=5, size=1000)
```

**2. PDF**
```python
expon.pdf(2, scale=5)   # Returns density at x=2
```

**3. CDF**
```python
expon.cdf(3, scale=5)   # P(X ≤ 3)
```

**4. Probability Between Two Values**
```python
# P(2 < X < 6) with mean=5
prob = expon.cdf(6, scale=5) - expon.cdf(2, scale=5)
```

**5. Mean, Variance, Std**
```python
print(expon.mean(scale=5))      # 5.0
print(expon.var(scale=5))       # 25.0
print(expon.std(scale=5))       # 5.0
```

---

## Visualizations

**PDF Plot**: Starts high at x=0 and decays exponentially  
**CDF Plot**: Starts at 0 and approaches 1 asymptotically

---

## Key Characteristics

- **Memoryless Property** (Very Important)
- Mean = Standard Deviation
- Positively skewed (right-skewed)
- Used heavily in **Poisson processes**
- "No memory" — future waiting time doesn't depend on past waiting time

## Step 2: Understanding `scale` ⭐⭐⭐⭐⭐

This is the **most important concept**.

Mathematically, the Exponential Distribution is written with **λ (lambda)** — the **rate** parameter.

But in SciPy, you do **NOT** pass λ directly.  
Instead, you pass:

**`scale = 1 / λ`**

This is because `scale` represents the **mean** waiting time.

### Examples:

- If λ = 5, then `scale = 1/5 = 0.2`
- If λ = 2, then `scale = 1/2 = 0.5`
- If λ = 0.5, then `scale = 1/0.5 = 2`

**Remember this table:**

| Mathematics     | SciPy              |
|-----------------|--------------------|
| λ (rate)        | 1 / scale          |
| Mean            | scale              |

This is the **most common beginner mistake**.

## Step 3: Generate Random Numbers

Suppose λ = 2 (mean = 0.5):

```python
numbers = expon.rvs(scale=1/2, size=10)
print(numbers)
```

**Possible Output:**
```
[0.18 0.91 0.34 0.07 1.25 0.42 0.29 0.65 0.12 0.88]
```

**Note**: All values are **≥ 0** because waiting time can never be negative.

---

## Step 4: PDF (Probability Density Function)

Find the density at x = 2 (with λ = 2):

```python
expon.pdf(2, scale=1/2)
```

**Output**: ≈ 0.0366

Unlike Uniform Distribution, the density **decreases** as x increases.

---

## Step 5: CDF (Cumulative Distribution Function)

Find P(X ≤ 2):

```python
expon.cdf(2, scale=1/2)
```

**Output**: ≈ 0.9817

---

## Step 6: Survival Function 

Instead of writing `1 - expon.cdf(...)`, SciPy provides a better function:

```python
expon.sf(2, scale=1/2)   # P(X > 2)
```

**Output**: ≈ 0.0183

The **Survival Function (sf)** is preferred for numerical stability, especially for small probabilities.

---

## Step 7: Mean

```python
expon.mean(scale=1/2)   # Output: 0.5
```

---

## Step 8: Variance

```python
expon.var(scale=1/2)    # Output: 0.25
```

---

## Step 9: Standard Deviation

```python
expon.std(scale=1/2)    # Output: 0.5
```

**Important**: In Exponential Distribution, **Mean = Standard Deviation**

---

## Step 10: Plot PDF

```python
x = np.linspace(0, 5, 100)
y = expon.pdf(x, scale=1/2)

plt.plot(x, y)
plt.title("Exponential Distribution PDF")
plt.xlabel("Time")
plt.ylabel("Density")
plt.show()
```

You will see a curve starting high at x=0 and decaying exponentially.

---

## Step 11: Plot CDF

```python
x = np.linspace(0, 5, 100)
y = expon.cdf(x, scale=1/2)

plt.plot(x, y)
plt.title("Exponential Distribution CDF")
plt.xlabel("Time")
plt.ylabel("Probability")
plt.show()
```

The graph starts at 0 and gradually approaches 1.
