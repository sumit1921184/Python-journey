**Python `rvs()` Cheat Sheet**

### 1. Bernoulli Distribution
**Parameter:**  
- \( p \) = Probability of success

```python
from scipy.stats import bernoulli
bernoulli.rvs(p=0.7, size=100)
```

**Sample Output:** `0 1 1 0 1 1 ...`

---

### 2. Binomial Distribution
**Parameters:**  
- \( n \) = Number of trials  
- \( p \) = Probability of success

```python
from scipy.stats import binom
binom.rvs(n=10, p=0.5, size=100)
```

**Sample Output:** `5 6 4 7 3 ...`

---

### 3. Poisson Distribution
**Parameter:**  
- \( \mu \) = Average rate (\( \lambda \))

```python
from scipy.stats import poisson
poisson.rvs(mu=5, size=100)
```

**Sample Output:** `4 6 5 3 8 ...`

---

### 4. Uniform Distribution
**Parameters:**  
- \( \text{loc} = a \) → Lower bound  
- \( \text{scale} = b - a \) → Width

**Example:** Range 10 to 20

```python
from scipy.stats import uniform
uniform.rvs(loc=10, scale=10, size=100)
```

---

### 5. Normal Distribution
**Parameters:**  
- \( \text{loc} = \mu \) → Mean  
- \( \text{scale} = \sigma \) → Standard deviation

```python
from scipy.stats import norm
norm.rvs(loc=170, scale=10, size=100)
```

---

### 6. Exponential Distribution
**Mathematics:** \( \text{rate} = \lambda \)

**SciPy Parameter:** `scale = 1/\lambda`

**Example:** \( \lambda = 4 \)

```python
from scipy.stats import expon
expon.rvs(scale=1/4, size=100)
```

---

### 7. Log-Normal Distribution
**Mathematics:** \( \ln(X) \sim N(\mu, \sigma^2) \)

**SciPy Parameters:**  
- \( s = \sigma \)  
- \( \text{scale} = e^{\mu} \)

**Example:** \( \mu = 2 \), \( \sigma = 0.5 \)

```python
from scipy.stats import lognorm
import numpy as np

lognorm.rvs(s=0.5, scale=np.exp(2), size=100)
```
