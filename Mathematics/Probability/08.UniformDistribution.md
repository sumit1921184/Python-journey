
# Uniform Distribution - Complete Detailed Notes

The **Uniform Distribution** is one of the simplest and most important probability distributions. It models situations where every outcome in a range is **equally likely**.

---

## What is Uniform Distribution?

- Also known as **Rectangular Distribution**.
- All values within an interval **[a, b]** have **equal probability**.
- Used when we have no reason to believe any value is more likely than another.

### Types:
1. **Discrete Uniform** – Takes finite number of values (e.g., rolling a fair die)
2. **Continuous Uniform** – Takes any value in an interval (most common in interviews)

---

## Key Properties Table

| Property              | Formula                          | Description                                      |
|-----------------------|----------------------------------|--------------------------------------------------|
| **Mean (μ)**          | (a + b) / 2                      | Midpoint of the interval                         |
| **Median**            | (a + b) / 2                      | Same as mean                                     |
| **Mode**              | Any value in [a, b]              | No unique mode (all values equally likely)       |
| **Variance (σ²)**     | (b - a)² / 12                    | Measure of spread                                |
| **Standard Deviation (σ)** | (b - a) / √12                | √Variance                                        |
| **Range**             | b - a                            | Length of interval                               |

---

## Formulas (Continuous Uniform Distribution)

### 1. Probability Density Function (PDF)

For **X ~ U(a, b)**:

$$
f(x) = 
\begin{cases} 
\frac{1}{b-a} & \text{if } a \leq x \leq b \\
0 & \text{otherwise}
\end{cases}
$$

- Constant height = **1 / (b - a)**

### 2. Cumulative Distribution Function (CDF)

$$
F(x) = P(X \leq x) =
\begin{cases} 
0 & \text{if } x < a \\
\frac{x - a}{b - a} & \text{if } a \leq x \leq b \\
1 & \text{if } x > b
\end{cases}
$$

### 3. Probability Between Two Values

$$
P(c < X < d) = \frac{d - c}{b - a} \quad \text{(where } a \leq c < d \leq b\text{)}
$$

### 4. Moment Generating Function (Optional)

$$
M(t) = \frac{e^{tb} - e^{ta}}{t(b-a)}
$$

## Python Implementation (SciPy)

```python
from scipy.stats import uniform
import numpy as np
import matplotlib.pyplot as plt
```

**Important Parameter Mapping:**

- `loc = a` (lower bound)
- `scale = b - a` (length of interval)

---

### Code Examples

**1. Generate Random Numbers**
```python
# U(0, 10)
data = uniform.rvs(loc=0, scale=10, size=1000)
```

**2. PDF**
```python
uniform.pdf(5, loc=0, scale=10)   # Returns 0.1
```

**3. CDF**
```python
uniform.cdf(6, loc=0, scale=10)   # Returns 0.6
```

**4. Probability Calculation**
```python
# P(3 < X < 7) for U(0,10)
prob = uniform.cdf(7, loc=0, scale=10) - uniform.cdf(3, loc=0, scale=10)
```

**5. Mean, Variance, Std**
```python
print(uniform.mean(loc=0, scale=10))      # 5.0
print(uniform.var(loc=0, scale=10))       # 8.333...
print(uniform.std(loc=0, scale=10))       # ~2.886
```

---

## Visualizations

**PDF Plot**: Flat horizontal line (rectangle)  
**CDF Plot**: Straight line increasing from 0 to 1

---

## Key Characteristics

- **Symmetrical** around the mean
- **Memoryless** in a certain sense (conditional probability within interval)
- **Minimum variance** among all distributions with same range
- **Easiest to sample** from

---

## Common Real-Life Examples

- Random number generation
- Manufacturing tolerances
- Waiting time for a bus (if schedule is perfectly uniform)
- Random selection of a point on a line segment
- Modeling rounding errors

# Uniform Distribution in Python

Let's learn Uniform Distribution step by step, just like the Standard Normal Distribution.

---

## Step 1: Import Libraries

```python
from scipy.stats import uniform
import numpy as np
import matplotlib.pyplot as plt
```

---

## Step 2: Understanding `loc` and `scale`

This is the **most important concept** in SciPy's Uniform Distribution.

Mathematically:  
**X ~ U(a, b)**

In SciPy:  
**uniform(loc=a, scale=b-a)**

- `loc` = starting point (lower bound)
- `scale` = length of the interval (NOT the ending point)

### Examples:

**Example 1:** X ~ U(0, 10)  
```python
uniform(loc=0, scale=10)
```

**Example 2:** X ~ U(20, 40)  
```python
uniform(loc=20, scale=20)
```

**Example 3:** X ~ U(5, 15)  
```python
uniform(loc=5, scale=10)
```

---

## Step 3: Generate Random Numbers

Generate 10 random numbers between 0 and 10:

```python
numbers = uniform.rvs(loc=0, scale=10, size=10)
print(numbers)
```

**Possible Output:**
```
[4.62 7.18 1.04 9.12 3.55 8.41 2.98 6.71 0.53 5.94]
```

All values will lie between **0 and 10**.

---

## Step 4: PDF (Probability Density Function)

For X ~ U(0, 10):

```python
uniform.pdf(3, loc=0, scale=10)   # Output: 0.1
uniform.pdf(8, loc=0, scale=10)   # Output: 0.1
uniform.pdf(5, loc=0, scale=10)   # Output: 0.1
```

The density is **constant** throughout the interval.

Outside the interval:
```python
uniform.pdf(15, loc=0, scale=10)  # Output: 0
```

---

## Step 5: CDF (Cumulative Distribution Function)

For X ~ U(0, 10):

```python
uniform.cdf(4, loc=0, scale=10)   # Output: 0.4
uniform.cdf(8, loc=0, scale=10)   # Output: 0.8
```

Outside the interval:
```python
uniform.cdf(-2, loc=0, scale=10)  # Output: 0
uniform.cdf(15, loc=0, scale=10)  # Output: 1
```

---

## Step 6: Probability Between Two Values

Find **P(3 < X < 7)**:

```python
prob = uniform.cdf(7, loc=0, scale=10) - uniform.cdf(3, loc=0, scale=10)
print(prob)  # Output: 0.4
```

---

## Step 7: Mean

```python
uniform.mean(loc=0, scale=10)   # Output: 5.0
```

---

## Step 8: Variance

```python
uniform.var(loc=0, scale=10)    # Output: 8.333333333333334
```

---

## Step 9: Standard Deviation

```python
uniform.std(loc=0, scale=10)    # Output: 2.886751345948129
```

---

## Step 10: Plot PDF

```python
x = np.linspace(0, 10, 100)
y = uniform.pdf(x, loc=0, scale=10)

plt.plot(x, y)
plt.title("Uniform Distribution PDF")
plt.xlabel("X")
plt.ylabel("Density")
plt.show()
```

You will see a **flat rectangle** (constant height = 0.1).

---

## Step 11: Plot CDF

```python
x = np.linspace(0, 10, 100)
y = uniform.cdf(x, loc=0, scale=10)

plt.plot(x, y)
plt.title("Uniform Distribution CDF")
plt.xlabel("X")
plt.ylabel("Probability")
plt.show()
```

The CDF is a **straight line** rising from 0 to 1.
