### Introduction
The **Binomial Distribution** tells us the probability of getting a certain number of successes in a **fixed number of independent trials**.

Each trial is like a Bernoulli trial (only success or failure).  
Binomial is simply the sum of multiple Bernoulli trials.

Example: Toss a coin 10 times → How many Heads (successes) will you get?

---

### Why Binomial Distribution Exists
In real life, we often do the **same experiment multiple times**. We need to know the probability of getting exactly k successes out of n trials. Binomial Distribution makes this easy.

---

### Real-Life Examples
- Number of heads in 10 coin tosses
- Number of students who pass an exam out of 30
- Number of defective items in a batch of 50 products
- Number of people who click on an ad out of 100 visitors
- Number of rainy days in a week (7 days)
- Number of successful free throws out of 8 attempts

---

### Random Variable
Let **X** be the random variable.  
X = number of successes in **n** trials.

- n = total number of trials (fixed)
- p = probability of success in one trial
- X can be 0, 1, 2, ..., n

---

### Probability Mass Function (PMF) - Human Readable Form

**In simple words:**  
It gives the probability of getting **exactly k successes** in n trials.

**Easy Formula:**
P(X = k) = C(n, k) × p^k × (1-p)^{n-k}    for k = 0 to n

**What each part means:**
- C(n, k) = Number of ways to choose k successes out of n trials (also written as "n choose k")
- p^k = Probability of k successes
- (1-p)^{n-k} = Probability of (n-k) failures

**Example**: n=5 trials, p=0.5 (fair coin), k=3 heads  
P(X=3) = C(5,3) × (0.5)^3 × (0.5)^2

---

### Why PMF is Needed
It helps us calculate the exact probability of getting any number of successes (0 to n). Without it, we cannot find chances of different outcomes.

---

### Expected Value (Mean) – Intuition + Derivation

**Intuition**: On average, how many successes do you expect in n trials?

**Formula**: Mean = **n × p**

**Derivation** (Simple):  
Each trial has expected value p.  
There are n independent trials → Total expected value = n × p

---

### Variance – Intuition + Derivation

**Intuition**: How much the number of successes usually varies from the average.

**Formula**: Variance = **n × p × (1-p)**

**Derivation**:  
Each Bernoulli trial has variance p(1-p).  
Since trials are independent, total variance = n × p(1-p)

---

### Standard Deviation
SD = √[n × p × (1-p)]

---

### Graphs
- It is a **bar graph** with bars from X=0 to X=n.
- Shape depends on p:
  - If p = 0.5 → Symmetric bell shape
  - If p < 0.5 → Skewed to the right
  - If p > 0.5 → Skewed to the left
- As n increases, the graph looks more like a Normal curve.

---

### Python Coding

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import binom

n = 10   # number of trials
p = 0.6  # probability of success

# Mean, Variance, SD
print("Mean (Expected successes):", n*p)
print("Variance:", n*p*(1-p))
print("Standard Deviation:", np.sqrt(n*p*(1-p)))

# PMF - Probability of exactly k successes
k = np.arange(0, n+1)
pmf = binom.pmf(k, n, p)

# Plot
plt.bar(k, pmf)
plt.title(f'Binomial Distribution (n={n}, p={p})')
plt.xlabel('Number of Successes (k)')
plt.ylabel('Probability')
plt.show()
```

### Common Interview Questions with Answers (25 Questions)

1. **What is Binomial Distribution?**  
   Answer: It gives the probability of getting exactly k successes in n independent trials, each with success probability p.

2. **What is the PMF of Binomial?**  
   Answer: P(X=k) = C(n,k) × p^k × (1-p)^{n-k}

3. **What is the mean?**  
   Answer: Mean = n × p

4. **Derive the mean.**  
   Answer: Each trial has mean p, so n trials → n*p

5. **What is the variance?**  
   Answer: n × p × (1-p)

6. **Derive the variance.**  
   Answer: Each trial variance = p(1-p), total = n × p(1-p)

7. **What is Standard Deviation?**  
   Answer: √[n p (1-p)]

8. **What is C(n,k)?**  
   Answer: "n choose k" = n! / (k! × (n-k)!)

9. **Binomial vs Bernoulli?**  
   Answer: Bernoulli = 1 trial (n=1). Binomial = n trials.

10. **Is Binomial discrete or continuous?**  
    Answer: Discrete.

11. **What happens when p=0.5?**  
    Answer: The distribution is symmetric.

12. **What happens when n=1?**  
    Answer: It becomes Bernoulli Distribution.

13. **Give real-life examples.**  
    Answer: Number of defective products in a batch, number of passes in a class.

14. **What is the range of X?**  
    Answer: X = 0, 1, 2, ..., n

15. **When does Binomial look like Normal?**  
    Answer: When n is large and np and n(1-p) both > 5.

16. **What is q?**  
    Answer: q = 1-p

17. **Can p be greater than 1?**  
    Answer: No.

18. **Where is Binomial used?**  
    Answer: Quality control, A/B testing, election predictions.

19. **What is the sum of all probabilities?**  
    Answer: Always 1.

20. **Mean is 5, n=10. What is p?**  
    Answer: p = Mean/n = 0.5

21. **Describe graph when p=0.8 and n=10.**  
    Answer: Skewed to the left (more successes likely).

22. **Use in Machine Learning?**  
    Answer: Used in binary classification when there are multiple trials.

23. **Write PMF formula.**  
    Answer: P(X=k) = C(n,k) p^k (1-p)^{n-k}

24. **What is the maximum possible variance?**  
    Answer: When p=0.5, variance = n/4

25. **Write code to calculate mean.**  
    Answer: `print(n * p)`

**Answer**: C(10,6) × (0.5)^6 × (0.5)^4

**Q3.** n=5, p=0.3. What is expected number of successes?  
**Answer**: 1.5

**Q4.** When is the distribution symmetric?  
**Answer**: When p = 0.5

- Using wrong variance formula
- Thinking it is continuous
- Forgetting to check np and n(1-p) before Normal approximation
